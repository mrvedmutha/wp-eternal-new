## Overview

Two new Gutenberg blocks for the Contact page. Both are placed side-by-side in the editor via a standard two-column layout or a wrapping section block.

| Block slug | Purpose |
|------------|---------|
| `wp-rig/contact-form` | CF7-powered contact form, left column |
| `wp-rig/contact-info` | Editable info panel + CTAs, right column |

---

## Block 1: `wp-rig/contact-form`

### Behaviour
- Renders a Contact Form 7 form via `do_shortcode()`.
- Block sidebar attribute: **CF7 Form ID** (integer, default `0`). Editor shows a text input; render.php uses `[contact-form-7 id="{id}"]`.
- If Form ID is `0` / unset, renders a placeholder message in the editor only.

### CF7 Form Template (to be created manually in WP Admin after block is built)

```
<div class="cf7-name-row">
  [text* first-name placeholder "First name"]
  [text* last-name placeholder "Last name"]
</div>

[email* your-email placeholder "your@email.com"]
[text* country placeholder "Country"]
[text order-number placeholder "Your Order Number"]

<p class="cf7-field-label">TOPICS*</p>
[radio topics use_label_element "Orders & Returns" "General Enquires" "Privacy & Data"]

[textarea comments placeholder "Message"]

<p class="cf7-disclaimer">Please do not include any sensitive personal data, including health information, in this form.</p>

[submit "SUBMIT"]

<p class="cf7-legal">By clicking Submit button I agree to ETERNAL-LABS <a href="/terms-conditions">TERMS &amp; CONDITIONS</a> and <a href="/privacy-policy">PRIVACY POLICY</a>.</p>
```

## CF7 Email Setup (Post-Build Step)

After the block is built and CF7 form is created in WP Admin:

**Mail tab (admin notification)**
- To: `[_site_admin_email]` or your preferred address
- Subject: `New Contact Form Submission – [topics]`
- Body: include all field tags

**Mail (2) tab — skip**, not needed per user decision.

**Flamingo plugin** — not required; submissions reviewed via email only.

---

## Build Order

1. Scaffold `contact-form` block via `npm run block:new`
2. Scaffold `contact-info` block via `npm run block:new`
3. Write `block.json`, `render.php`, `src/index.js`, `src/style.scss` for both
4. Run `npm run build` to compile
5. User creates CF7 form in WP Admin using the template above
6. User pastes CF7 Form ID into the `contact-form` block sidebar in the editor

---

## Out of Scope

- Flamingo / database submission storage
- User auto-reply email (Mail 2)
- Country dropdown (free text confirmed)
- Any animation or transition on form fields
